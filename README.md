
# 💰 Student Expense Tracker

A simple and responsive Student Expense Tracker website built using HTML, CSS, and JavaScript. It helps students manage their daily expenses and track their spending easily.

## 🚀 Features

- Add daily expenses with name, amount, and category.
- View all added expenses.
- Calculate total expenses automatically.
- Delete individual expenses.
- Filter expenses by category.
- Validate empty fields and invalid amounts.
- Responsive design for mobile and desktop.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and managing your expenses!

## 📸 Project Preview

The website provides a simple interface to add expenses, view the total amount, delete records, and filter expenses by category.

## 🎯 Objective

The main objective of this project is to help students track their daily spending, manage their budget, and develop better money-management habits.
